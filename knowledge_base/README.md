# Knowledge Base

Put official IRS/state instructions and firm reference notes here.

Readable files are loaded automatically when the server starts or when a review runs:

- `.txt`
- `.md`
- `.csv`
- `.json`

Recommended naming:

- `irs-1120-instructions-2024.md`
- `ca-100-instructions-2024.md`
- `ny-ct-3-instructions-2024.md`
- `firm-review-policy.md`

PDFs are not parsed from this folder by the backend yet. If you have official instructions as PDFs, export the relevant sections to `.md` or `.txt`.
